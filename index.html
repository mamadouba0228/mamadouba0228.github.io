Applications

Deux applications cartographiques que j'ai conçues et développées. Vous pouvez les tester directement.

SonkeMap, calcul d'itinéraire en Guinée

Application web de calcul d'itinéraire pensée pour les routes guinéennes : recherche du départ et de la destination, tracé du trajet, instructions de navigation vocales et signalement des dangers sur la route. Elle s'installe sur un téléphone comme une application.

  • JavaScript
  • OpenLayers
  • OpenRouteService
  • PHP
  • Application web installable (PWA)
Tester l'application Voir le code

Guinée Carto, cartographie participative

Application de collecte collaborative pour enrichir la carte de la Guinée. Chacun peut ajouter un lieu, une route ou une zone depuis son téléphone, avec son état, sa praticabilité, son revêtement et une photo. Les contributions sont enregistrées hors ligne, envoyées dès le retour du réseau, puis vérifiées avant publication sous licence ouverte (ODbL).

  • Collecte terrain
  • Mode hors ligne
  • Modération des contributions
  • Application web installable (PWA)
  • Licence ODbL
